# Prepared index delivery admission

Prepared pool publication now requires an index preflight contract. A legacy sink remains sufficient for ordinary streaming, but cannot authorize `PublishPreparedBatch`.

After reserving new CPU arena ranges, the pool constructs the complete prospective flush delta: existing removals, removals for replaced residents, retained pending writes, replacement writes with their actual reserved slots, and pending GPU additions. The index reserves packet array capacities and pilot credits before any resident is removed. Failure returns arena reservations. Sink generation, pool epoch, pool mutation sequence and index epoch/generation/shadow revision are checked before commitment.

The synchronous commit has no rejectable work: the pool enqueues its writes, and the reserved delivery feeds its preallocated packet into the existing index capture path. Actual-versus-prospective delta comparison is an invariant check, never a claim that an already-published pool batch was rolled back. The temporary active-reservation pointer is borrowed only during that synchronous call and never captured by render commands.

Real reservations are created by the attached march index. The separate `VoxelPreparedIndexTestSupport` adapter exists only under development automation for tests concerned with pool allocation rather than real index delivery; production never falls back to it.

The pilot has 128 MiB of per-index outstanding reservation credits. Admission includes existing annotation dirty cells, full-versus-patch capacity, three coarse arrays, maximum GPU entries and the copied expected delta. Arithmetic promotes individual counts before addition/multiplication and checks narrowing limits. Actual array allocation sizes, including allocator slack, are charged before commitment. Append fills the reserved storage without shrinking/copy-assignment reallocations. Credits accompany the queued packet and retire on command completion or cancellation; unused capture storage and copied expected deltas are freed before local credits are released. Externally retained consumed tokens own no packet arrays. A temporary credit reference also covers cleanup if the RT executes the moved packet before the GT commit returns.

This budget covers prepared-delivery array storage. It is **not a global streaming-memory cap**: ordinary packets, GT/RT cell maps and sets, the pool's own prospective delta, render-command/RHI allocations and general allocator/object overhead remain outside it. Out-of-memory termination is not converted into a recoverable allocation protocol. Ordinary publication preserves its existing behavior; adopting the budget globally still requires producer admission before every mutation. No accepted packet is silently dropped to meet a cap.
