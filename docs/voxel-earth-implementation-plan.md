## 1. Project Vision

A multiplayer, Earth-realistic, procedurally generated world made of **10cm cubic voxels**, where *everything* is destructible — terrain (fully volumetric to bedrock), trees, structures, and characters (players and NPCs are voxel bodies that can be chopped/deformed). Terrain realism comes from **terrain-diffusion** (https://github.com/xandergos/terrain-diffusion), a learned diffusion-based terrain generator producing infinite, seed-deterministic elevation + climate rasters at 30m/px, instead of Perlin-class noise.

### Locked product decisions (from design sessions)
| Decision | Choice |
|---|---|
| Engine | **UE5 + custom C++ voxel core** (engine-agnostic core lib; UE hosts rendering/netcode/tools) |
| Players | **2–16 co-op**, server-authoritative; player-hosted servers viable; offline single-player supported via same abstraction |
| World persistence | **Time freezes when server offline** (no catch-up sim) |
| Visual target | Between Minecraft readability and Teardown micro-voxel realism; crisp cubes + PBR materials + voxel-face AO |
| LOD transitions | **Dithered cross-fade** (blue-noise screen-door, resolved by TSR) between rings and at voxel→heightmap boundary |
| Destructibility depth | **Fully volumetric to bedrock**, but deep digging is rare → lazy underground instantiation |
| Min-spec | **RTX 3060-class** target; may raise to high-end if forced. HW-RT Lumen is ultra-only |
| GI | **Voxel-native GI as baseline** (propagated voxel light field + cone tracing against existing voxel mip chain); HW-RT Lumen ultra preset |
| NPCs | Wildlife + near-player humans + persistent settlements (all eventually). **NPCs dig and build.** Dozens active normally, support ~hundreds in surges |
| Water | **Full showpiece**: pressure CA (authority) + SWE surge patches + client particles. Water **is a gameplay force** (currents push players/debris; boats later). Rivers **fully dynamic** (dam/divert/flood downstream) |

## 2. Core Architecture Doctrine (INVARIANTS)

1. **The world is a deterministic function, not data.** `voxel(x,y,z) = f(seed, x, y, z)` evaluated lazily. Only *diffs* are ever stored or transmitted.
2. **Never replicate voxels.** The network carries: (a) the seed, (b) diffusion tiles (~1.5MB per 512² tile covering ~236 km²), (c) an append-only **edit log** of brick diffs (RLE-compressed), (d) small state (hydrology graph diffs, entity replication).
3. **Determinism boundary:** Diffusion model output is NOT bit-deterministic across GPUs → treat tiles as **canonical data generated once server-side and distributed**. Everything below 30m — the amplifier (11m→0.1m detail synthesis), voxelization, water CA — MUST be **bit-deterministic integer/fixed-point math** so all clients derive identical worlds from tiles + edit log. This is the load-bearing wall of multiplayer. Test it continuously (NVIDIA vs AMD CI runs).
4. **One authority path for world changes.** Player digs, NPC builds, water flow, settlement growth — ALL become edit-log entries (server-authored). Replication, persistence, LOD invalidation, rendering all hang off this single mechanism.
5. **Everything expensive is budgeted, never demand-driven.** Per-frame caps on bricks amplified/meshed, BLAS updates, tile uploads; priority queue by screen-space error; hysteresis on load/unload. Worst-case frame cost is a chosen constant.
6. **Offload to server only what is cacheable and client-independent** (tiles, far-LOD vista meshes, nav graphs, biome metadata → CDN). Never per-client or per-frame work (bandwidth loses to local recompute by ~5 orders of magnitude).

## 3. System Specifications

### 3.1 Terrain generation cascade
1. **Coarse planetary map** (diffusion, ~7.7km/px): continents, climate zones.
2. **Regional tiles** (terrain-diffusion-30m): int16 elevation (signed; z=0 is sea level) + 4 climate channels (temperature, seasonality, precipitation, precip variability). Generated by an async GPU worker (Flask API or embedded), cached forever (HDF5/content-addressed by seed+coords), CDN-distributed. Supersampling to 11.25m/px (scale=8) supported.
3. **Amplifier** (11m → 0.1m, GPU compute, bit-deterministic): slope+climate-conditioned integer-hash fractal noise; erosion/scree stamps; riverbed carving along flow lines; **material stratigraphy** per column (topsoil depth = f(slope, precip) → subsoil → sedimentary layers → bedrock at biome-conditioned depth) defined all the way down; 3D cave-carve noise pass (evaluated only for below-surface bricks); vegetation placement from climate (species, density, snow line).
4. **Voxelization** on demand into sparse bricks; only bricks intersecting the surface shell or touched by edits exist. Underground is implicit-solid until edited.

### 3.2 Voxel storage
- Bricks of 8³ or 16³ voxels (benchmark both in M0); occupancy bitmask + per-brick material palette; homogeneous bricks collapse to one value.
- 3D chunk keys, unbounded depth range. Hashed chunk map.
- Edit overlay: per-brick diff records; edit log is append-only, compacted offline.
- Voxel mip chain (2× downsample: parent solid if ≥N of 8 children solid, N≈4 tunable per material; majority material; averaged color). Mips serve BOTH render LOD and cone-traced GI.

### 3.3 Rendering & LOD (single screen-space-error metric τ drives everything)
- **Band 1 — R0 true voxels** (10cm), radius 64–512m by preset. GPU greedy meshing → pooled custom FPrimitiveSceneProxy buffers (NOT ProceduralMeshComponent). Per-quad: material ID + orientation; PBR texture arrays, world-space UVs, hash color variation, 4-neighbor corner voxel AO baked into verts.
- **Band 2 — voxel mip rings R1–R4** (20cm→1.6m cubes, out to ~2km). Power-of-two aligned: ring boundary = 8 cubes become 1 in place (no geometry sliding).
- **Band 3 — heightmap clipmap** (~2–30km, 1.25→30m/px; CDLOD/geometry clipmaps fed by partial-res amplifier + raw tiles).
- **Band 4 — horizon tiles** (30km→horizon, coarse map + CDN-baked vista meshes + atmospheric scattering).
- Log-scale property: each ring ≈ constant cost; view distance nearly free; only inner rings are expensive.
- **Transitions:** dithered cross-fade band (outer 15–20% of each ring; blue-noise threshold; both LODs rendered in band; TSR resolves). Watch for shimmer under fast camera motion — keep bands narrow.
- **Distant edits:** edits affecting ≥4m mip cubes propagate up the mip chain and invalidate overlapping heightmap patches (craters visible at 20km). Smaller edits don't exist beyond voxel rings.
- **User settings** (all remap τ + budgets): R0 radius, ring count, far distance (10–200km), streaming budget, VRAM cap, auto mode (frame-time governor).
- **Large World Coordinates + camera-relative rendering with origin rebasing** from day one (M1) — Earth scale breaks float precision otherwise.
- **Collision:** custom DDA raycasts/box-sweeps against brick grid for characters/projectiles. Chaos only for dynamic debris bodies (cooked per-body, not per-chunk terrain).
- **Lighting:** propagated voxel light field (sun + point lights, flood-fill per brick, incremental on edits — also solves underground/enclosed spaces) + voxel cone tracing against the mip chain for bounce/occlusion. HW-RT Lumen with per-chunk BLAS rebuild budget = ultra preset only.

### 3.4 Multiplayer
- One authoritative server process (CPU VPS or player-hosted). `ITerrainSource` abstraction with **Remote** (multiplayer) and **Local** (single-player/host) implementations — identical client code below the tile layer.
- Edits: client predicts locally, sends intent, server validates + broadcasts; brick-granularity reconciliation.
- Physics debris, all NPC AI, water authority: server-side; transforms/state replicated via standard UE replication.
- Bandwidth: KB/s class. 16 players trivial.
- Infra cost reality: diffusion worker = one 4090-class GPU (~$0.35–0.7/hr rented; serverless scale-to-zero recommended — generation cost scales with *newly explored area*, not players, and decays toward zero as cache fills). Pre-generate launch radius offline. Total production infra for co-op scale: <$100–600/mo.

### 3.5 Destruction & voxel bodies
- Edit → brick write → re-mesh touched bricks (sub-ms) → mip/nav/light invalidation.
- Connectivity flood-fill over affected region on structural edits → disconnected islands promoted to rigid voxel debris bodies (Chaos).
- Characters (players AND NPCs): skeleton where each bone owns a small brick grid, skinned by bone transform, meshed via the same path. Damage removes voxels from bone grids; severed connectivity → limb becomes debris. Distant/crowd characters keep bodies dormant until first hit (lazy wake into full tier).

### 3.6 NPCs & AI (simulation LOD)
- **Tier 0 — embodied** (near players, ~dozens; internal LOD: nearest ~30 get unique anim + per-bone bodies + per-frame AI; beyond that instanced crowd rendering, vertex-animation textures, staggered ticks; flow fields for hundreds-scale convergence events — one field shared by all agents).
- **Tier 1 — abstract** (loaded region, hundreds): nav-graph position + schedule, ~1Hz.
- **Tier 2 — statistical** (world-wide, thousands of settlements): aggregate population/resources/projects, slow ticks; emits **blueprint diffs** (pre-planned construction stamps) into the edit log over game-days. Promotion/demotion bubbles follow players.
- **Pathfinding:** hierarchical — server-computed region graph from tiles (CDN'd, lazily patched on large edits) + local windowed voxel A* where traversing air is cheap, digging costs (hardness × time), placing scaffold blocks has cost → walking, mining, tunneling, bridging fall out of ONE cost function. Incremental nav invalidation per dirty brick. Do NOT use stock UE NavMesh as primary.
- NPC terrain changes are ordinary server-authored edit-log entries (zero new machinery).

### 3.7 Water (four layers + force field)
**Generation:** ocean = z<0 implicit/infinite; lakes = basin detection on tiles gated by precip-vs-evaporation (dry basins → salt flats); rivers = flow-accumulation routing, discharge from upstream precip sets width/depth, amplifier carves channels; water table depth per column = f(precip, elevation, nearby bodies). Precompute per body: **hypsometric curve** (level↔volume) and **river segment graph** (connectivity + discharge).

**State machine per region:** Implicit static (level L, shader surface + underwater fog, zero data) ⇄ Active sim voxels (10cm cubes, fill fraction 0–255/voxel, ticked 10–20Hz GPU in dirty bricks) — both exchanging volume with **Reservoir entities** (volume + hypsometric level; ocean = infinite). Settled+flat → re-staticize at new level, voxel data evaporates.

**Layer B — pressure CA (THE AUTHORITY):** integer, bit-deterministic, volume-conserving; gravity then lateral equalization then hydrostatic column pressure (fills U-bends; breaching below water table = depth-scaled inrush jet). Works in full 3D topology (caves/tunnels). Server-side; replicate compressed fill-diffs for active regions (capped, e.g. few-thousand active bricks ≈ ~50m event).
**Layer C — SWE patches (virtual-pipes shallow water, GPU):** spawned by CA on large open-surface flux events; provides momentum — dam-break surge, flood fronts. Float, non-authoritative, client-reconstructible from CA state. CA ledger is ALWAYS the volume truth; SWE only renders and pushes. (The CA↔SWE volume handoff at patch boundaries is the fiddliest code in the project — guard against double-counting.)
**Layer R — river network sim:** segment graph ticks ~1Hz server-side (Muskingum-class storage routing). Dam → conveyance→0, upstream stage rises → spawn new reservoir behind dam; downstream discharge decays, beds dry over minutes. Divert → sustained CA flux promotes new channel to a segment. Burst dam → discharge spike → SWE flood patches where stage exceeds banks. Hydrology graph = base (from seed) + persistent replicated graph-diff log.
**Layer D — cosmetics (client, non-authoritative):** GPU splash particles from SWE curvature/velocity (50k min-spec → 1M ultra), shader foam/ripple decals (Teardown-style), spray.
**Force field:** authoritative coarse grid (~1m cells: velocity + surface height) derived server-side from CA/SWE, replicated ~5Hz, interpolated. Character controllers + debris buoyancy consume ONLY this. Buoyancy = submerged fraction (from CA fill) × displacement, drag vs local flow. Boats later = rigid voxel hulls riding the same two inputs.

## 4. Milestones (gates are hard pass/fail)

**M0 — Core + proof of numbers.** Terrain service (diffusion worker + tile protocol + disk cache, local & remote). Headless C++ voxel core: bricks/palettes, amplifier v0 (stratigraphy fill + integer hash noise), greedy mesher, benchmark harness. GATE: amplify+mesh 128m radius <1s on RTX 3060; **bit-identical amplifier output NVIDIA vs AMD**.
**M1 — Walkable world in UE5.** Custom scene proxies, R0 ring, materials + voxel AO, streaming ahead of walking player, dig/place via edit overlay, LWC + origin rebasing. GATE: walk & dig at 60fps on min-spec.
**M2 — LOD cascade.** Mip rings, heightmap clipmap, dithered cross-fades, presets, distant-edit propagation. GATE: 50km+ vista, 60fps, fast flight with no hitches (only ring coarsening).
**M3 — Multiplayer.** Server process, ITerrainSource remote/local, edit-log replication + prediction. Do BEFORE the world gets rich. GATE: two clients dig the same hole.
**M4 — Living world.** Biomes/vegetation/trees (generated voxel structures), cave pass, voxel light field + cone-traced GI. 
**M5 — Destruction.** Connectivity flood-fill, debris promotion, structural collapse, per-bone voxel character bodies.
**M6 — NPCs.** Region graph + dig-aware A*, Tier 0/1 agents + promotion, minimal Tier 2 settlement emitting blueprint diffs. → vertical slice.

**Water track** (parallel): W1 (with M1–M2) generation + implicit water, swimming, fog — world *looks* hydrated. W2 (after M3, networked from birth) pressure CA + reservoirs — breach/drain/flood/inrush. W3 river network sim. W4 SWE + force field. W5 particles/foam/buoyancy polish, boat-ready.

Team estimate: 2–4 strong engineers (≥1 real rendering/GPU person), M0–M3 ≈ 4–6 months, vertical slice ≈ 12–15 months. Historical slip risks: M2 transition polish, M5 structural collapse, W4 CA↔SWE coupling.

## 5. M0 — First Sprint (START HERE)

Repo layout (monorepo):
```
/terrain-service/   Python: terrain-diffusion worker, Flask tile API, HDF5 cache, Docker
/voxel-core/        C++20, UE-header-free, CMake: bricks, palettes, amplifier, mesher, editlog
/voxel-core/bench/  headless benchmark + determinism harness (CI on NV + AMD runners)
/ue-project/        UE5 project consuming voxel-core as a module (M1+)
/docs/              this file, ADRs (one per doctrine deviation)
```
Task order:
1. Stand up terrain-diffusion locally; wrap in tile API: `GET /tile?seed&x&y&scale` → elevation int16 + climate uint8[4]; disk cache; golden-tile regression test.
2. Brick storage + palette + bitmask; property tests (set/get/iterate, homogeneous collapse); benchmark 8³ vs 16³.
3. Amplifier v0: column stratigraphy from tile data + integer-hash fractal detail (fixed-point ONLY; document the hash). CPU reference implementation FIRST, then GPU compute port; CI asserts GPU==CPU bit-exact, and cross-vendor bit-exact.
4. Greedy mesher (CPU ref → GPU); benchmark bricks/sec and 128m-radius wall-clock.
5. Edit overlay + append-only log format (versioned, RLE brick diffs) + replay test: world(tiles) + log == world(tiles) + log, always.
Definition of done = both M0 gates green in CI.
