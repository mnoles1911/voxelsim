# Split stationary authority capture

The core capture API separates owner-thread admission, worker sampling and owner-thread acceptance. Admission checks the actual World binding, bounded unedited domain and immutable projection shape before dispatch. Sampling reads the pinned generated configuration and immutable source grids; it never reads the live World's terrain or craft overlay maps.

The trusted host lifetime interface must retain the actual generated instance, amplifier, providers, asset banks and identity adapter, and guarantee their immutable thread-safe configuration throughout sampling. Reconstructing a same-seed default World is insufficient. The host supplies edit, residency, configuration and object epochs from actual state; checking epochs afterward does not make concurrent mutation safe.

Acceptance checks the exact session lease, World and field identity, provider, epochs, terrain/craft log counts, domain absence and catalog identity. Callback effects are rechecked before exposure. The coordinator rejects cancellation, recursion, competing publication and closed ownership before installing the result.

The coordinator reserves a bounded generation credit before admission. Cancellation marks the request without freeing storage still held by a worker or completed result. Each request runs once; result arrays and retained inputs are destroyed before their credit is released. Successful publication transfers the same credit to the immutable visible generation. Provider/grid backing storage and identity callback caches require a separate host budget.

This is a core visible-reference transaction, not the multi-resource renderer/World-log transaction. The UE lifetime lease, actual monotonic epoch source, ownership restore, query routing and joint edits remain separate integration. Production ownership is disabled. Focused regression source covers concurrent live World edits, stale sessions/epochs, retained cancellation quota, competing publication and callback reentrancy; the focused MSVC authority target passed all six cases (0.28 seconds). Live UE capture remains unconnected.
