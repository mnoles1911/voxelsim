WHAT WAS WRONG
--------------
D:\terrain-diffusion\_prep_stats.py records that WorldClim was unreachable when
the conditioning statistics were built, and that hand-written latitude formulas
were substituted for bio_1/4/12/15. The real WorldClim 2.1 10-arc-minute
rasters were present in data/global (dated 2019) and unused.

_load_stats_cache (synthetic_map.py:134-157) returns that file whenever it
exists. It is keyed on NOTHING -- make_synthetic_map_factory (:185-188) passes
frequency_mult and drop_water_pct only on a cache MISS, so on every real run
the shipped tables were consumed and the configured parameters were ignored.

Confirmed consumed, not inert: the cache file uses key names
(data_quantile_tables / noise_quantile_tables) that differ from the names
_compute_map_stats returns (base_image_quantiles_N / noise_quantiles_N). The
loader contains a translation layer, prints "Synthetic map stats cache hit.",
and returns 14 keys with both required names present.

THREE FINDINGS
--------------
1. ELEVATION IS BYTE-IDENTICAL fake vs real. It came from etopo_10m.tif, a
   real raster, all along -- _prep_stats.py only faked the four bio channels.
   This MATTERS for Wave 2b: the plan's finding that "the cached table implies
   22.6% of land above 1000 m while delivered is 1.4%, so the coarse model is
   compressing the tails" is UNAFFECTED by this fix. Do not expect Wave 1a to
   move relief. It cannot; the elevation table did not change.

2. PRECIPITATION IS THE FIX. IQR 441 -> 851 mm, p5 320 -> 39 mm, max
   2525 -> 6445 mm. The predicted p25/p50/p75 (296/588/1148) matched the
   measured (295.8/588.0/1147.2) to the decimal. This is the direct cause of
   the isohyetal world -- precipitation spanned 7.8% of its encodable range
   over land while temperature spanned 43.9%, collapsing every biome decision
   onto temperature and elevation.

3. TEMPERATURE NARROWS, and this was not predicted. Span 58.8 -> 43.1 C
   (fake -11.1..47.7, real -7.5..35.6). The real table is sea-level-EQUIVALENT
   temperature: _compute_map_stats:83-84 adds the lapse rate back out before
   building quantiles, and the crop is +/-60 deg latitude, so -7.5 C as a
   minimum is plausible. High terrain still gets cold because
   finalize_synthetic_map re-applies the lapse rate at :239-240, so
   TUNDRA_ALPINE and BARE_ROCK are unaffected. The cold END of the SEA-LEVEL
   ladder loses range -- expect less lowland TAIGA.

   Net: widening precipitation while narrowing temperature is what makes the
   climate genuinely two-dimensional, which was the goal. But it is a
   trade, not a pure win, and the biome census in Wave 1c should be read with
   that in mind.
