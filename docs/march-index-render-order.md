# Render-ordered march index staging

The game-thread pool sink previously replaced shared staging immediately after enqueueing pool uploads. An older queued view could consume that future index before the corresponding pool writes. End-of-frame actor proxy synchronization could not protect that older view.

The index now captures immutable per-flush packets and installs them at a specific position in the render-command stream, after their pool writes. Every packet carries an epoch, base/current generation, full seed or unique cell/value patches, all three coarse mirrors, verification hash and captured upload settings. Render consumers use only the installed image and mirrors. Later packets cannot modify an earlier queued packet.

The RT retains one 72 MiB CPU image (nine 128-cubed grids). Ordinary GT changes produce patches regardless of whether GPU uploading uses the full or sparse policy. Seed/reseed and patches larger than the image use one full packet. Coarse mirrors cost 108 KiB per packet. RT coalesces dirty cells only after each packet reaches its command position; full staging supersedes earlier patches. The GPU-resident publication branch executes inline at installation, so it cannot enqueue behind a view already waiting after that installation. Missing GPU resources retain the full CPU image for rebuilding.

Detach retires RT image, mirrors and pooled buffers in one ordered command, with a new epoch. Commands own shared lifetime state. An owner-lifetime lock prevents queued installation from calling a destroyed index; cancellation by owner destruction retires outstanding packet accounting. No production render flush or polling loop is introduced.

`GetQueuedIndexPacketBytes` measures outstanding immutable payload bytes, excluding allocator/container overhead. Each packet is finite, but the aggregate queue is intentionally **not capped**: the pool's existing index sink is called after pool mutation and cannot safely drop, overwrite or defer the matching state. Prepared pool publication now reserves packet capacity and a separate pilot budget before mutation; see `prepared-index-delivery.md`. Equivalent producer backpressure remains necessary before claiming a strict global queue-memory bound. This change does not publish production actors.

`Voxel.Objects.MarchOrderedIndex` queues an old view, constructs the next real index packet before allowing that view to read, and verifies old/new generations retain matching cell and coarse occupancy. It also exercises full/patch coalescing, malformed and stale epoch rejection, replacement epochs and owner destruction with queued preparation. Combined Unreal build passed17actions54.54s in `build-environment-ordered-rehearsal.log`; all33 DX12 object tests passed with normalexit0 in `environment-ordered-rehearsal-tests.log`, including this regression.
