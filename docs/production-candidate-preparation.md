# Canonical environment candidate preparation

Runtime opt-in commands: `voxel.Environment.PrepareCandidate` prepares the nearest eligible generated environment instance within 16 m of the player; `voxel.Environment.CancelCandidate` cancels it. There is no startup flag or automatic actor spawning. The result stays hidden and has no collision or tick. An explicit unpublished-preparation predicate excludes it from both modern object discovery/capture and legacy teardown capture; visibility alone does not define eligibility. Ordinary hidden live objects and existing restoring data records retain their persistence behavior. The success log explicitly reports `publicationReady=0`.

The bridge in `FVoxelWorldImpl::TickProductionCandidate` uses the real terrain resolver, production manifest bank ID/kind and seed index. It supports any manifest environment kind through flower that is authored on the 100 mm terrain lattice; no fixture/spec-name lookup is used. Fine provider identity and a successfully loaded manifest are required. Sparse 50/25 mm production promotion remains a later authoring/renderer step.

One tracked background worker selects a bounded canonical source. After game-thread residency and edit admission, a second tracked worker re-resolves the candidate's complete footprint, including all earlier overlapping winners, and uses `assetBuildCandidateVxa` for terrain/composition clipping. The resulting immutable sparse geometry and dynamic header feed the existing staged actor restore. One component upload is advanced per game tick. `PublishStagedObjectRestore` is never called.

Source provenance retains world seed, fine provider plus C++ worldgen version, manifest and canonical source content fingerprints, signed anchor, bank, seed, layer and original quarter yaw. `CanonicalSourceHash` hashes original grid dimensions/origin/pitch and decoded material cells independently of compression. `ClippedGeometryHash` hashes the clipped VXA bytes separately and is the actor descriptor's SourceHash. The retained preparation record and optional schema-2 actor descriptor both preserve the canonical provenance and source hash. The actor transform is translation-only because canonical yaw is already baked into clipped voxel indices.

Admission/revalidation:

- Fine residency is checked over the selection/full source rectangle dilated by maximum terrain-asset anchor reach. The streamer's own gate adds its carrier/cavern sampling margin.
- Edit and fine residency epochs are captured before work and checked each tick, including after worker completion and during actor staging. Any change cancels the prepared result conservatively, including unrelated terrain changes elsewhere.
- Every geometrically touched page, including aprons at all eight renderer levels, is enumerated as a bounded superset. This covers present/future visible, pending and parked pages; current state counts are diagnostics, not a publication-ready snapshot.
- Level-zero page admission scans the existing edited-brick overlay (including projected craft edits) and rejects overlaps conservatively. A second scan follows clipping.
- Cancellation marks shared worker state, destroys the hidden actor and refuses new preparation while an old Impl-borrowing worker remains active. Both workers enter existing InFlightTasks; deinitialization cancels then waits before freeing bank/manifest/sampler inputs.

Limits: one candidate per world; 8 Mi source cells; 65,536 source columns; 8,192 resolved instances and touched pages; 64 m maximum terrain layer reach; 32 MiB clipped VXA/snapshot payloads; 64 page inspections per tick; one component upload per tick; 90 seconds total preparation/hidden retention. Candidate enumeration and clipping are bounded background work, not preemptible per-voxel jobs. Standard allocator exhaustion remains Unreal's fatal OOM policy. An indivisible component upload can still exceed a frame budget.

Automation `Voxel.Objects.ProductionCandidateAdmission` checks stale edit/residency epochs, retained cancelled worker results, negative page aprons, coarse levels and fail-closed page limits. `Voxel.Objects.ProductionCandidateSnapshot` checks compression-independent source identity, arbitrary descriptors, immutable sparse encoding, retained canonical yaw and translation-only collision-disabled actor input. `Voxel.Objects.ProductionCandidatePersistence` is a latent regression for registry count and successful whole-world snapshots before/while/after hidden staging and cancellation, retained normal restoring records, hidden live actors, and the legacy teardown failure latch. All passed in the 23-test DX12 object suite, process exit0, `D:/voxelsim/Saved/environment-proof-lifetime-tests.log`. UE build succeeded in `build-environment-proof-lifetime.log`; unity, switch coverage, float-boundary and shader UB checks pass. Real-world command execution is being verified separately.

Still required: generation-captured CPU/GPU request markers, full held terrain page preparation, atomic terrain-index/object reveal, parked/adoption cancellation, registry/provenance restoration and edited coarse projections, multiplayer ownership synchronization and cross-chunk visual acceptance. A successfully prepared hidden actor is not a completed ownership handoff.

## Optional persisted production source identity

Generic environment identity remains marker -1/schema 1, and legacy markers 0..3 remain byte-compatible. Production candidates now write schema 2 only when complete production provenance is present. The optional descriptor stores every `AssetProvenance` field, its derived 128-bit identity, and canonical source content hash separately from the clipped `SourceHash`. Fields use fixed-width serialization rather than native struct padding. Loading older identities clears any optional provenance previously held by the destination descriptor.

Validation rejects partial fingerprints, mismatched descriptor/source seed indices, yaw outside 0..3, anchors outside +/-2^30 base voxels, malformed hashes, truncation, and a stored identity that differs from the full source fields. Zero world seeds remain valid. Generic preparation fixtures without production fingerprints keep schema 1. This persists source metadata only: it does not bind the registry stable ID, publish ownership, reveal actors, or establish complete save/reload integration.

Automation `Voxel.Objects.EnvironmentProvenance` and `Voxel.Objects.CandidateProvenance` passed in the 25-test object suite, process exit0, `D:/voxelsim/Saved/environment-provenance-tests.log`. This includes schema2 round-trips, old readers and malformed/truncated payload rejection.
