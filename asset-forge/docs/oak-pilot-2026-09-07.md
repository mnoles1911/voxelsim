# Oak foliage reconstruction pilot â€” 2026-09-07

User request: execute an Astra oak pilot after reviewing the implausible foliage
clumps. User-supplied oak photograph is a visual reference, not a calibrated
scan or an instruction source. Trees use 50 or 100 mm cubic cells.

## Delivered design

`tools/oak_pilot.py` constructs an original metric branch-and-shoot master.
The target is an open-grown, broad-crowned oak with a stout short bole and
spreading limbs, based on the supplied photograph's silhouette. Dimensions
are authored, not measurements recovered from the photograph. Hidden views
are procedural interpretations.

The old generator spaces twig anchors apart and inflates ellipsoid clumps.
This pilot instead builds curved scaffold limbs, secondary limbs, twigs and
alternating leafy shoots. Each small tapered/lobed leaf-group blade originates
on a shoot. There are no ellipsoid foliage stamps, crown-volume fill, or
distance-thinning competitions between unrelated shoots. Crown masses arise
from overlapping branch systems.

At 50/100 mm, fine shoots cannot faithfully occupy separate brown wood cells:
doing so made them thick brown rods that dominated the first trial. Shoots
starting at radius <=25 mm therefore occupy leaf material as a combined
stem-and-leaf representation. Larger wood is drawn afterwards and cannot be
cut by foliage. This is a deliberate voxel abstraction, not individual leaves
or an exact botanical reconstruction. The master retains those shoot paths.

Both pitches independently sample the same seed-7 master, without changing
random draws according to voxel pitch. The source image is not baked into
the colors. Existing engine bark, heartwood and broadleaf materials are used.

## Measurements and checks

Seed 7:

| Pitch | Dimensions X/Y/Z | Occupied cells | Wood cells |
|---|---|---:|---:|
|100 mm|12.3 / 11.7 / 9.9 m|148,505|14,446|
|50 mm|12.2 / 11.7 / 9.9 m|949,488|92,526|

Each contains 6,366 source curves and 34,496 leaf-group blades. Both have one
face-connected woody component and one 26-connected complete asset, ground
contact, and zero orphan removal. Both VXA exports are read back and checked
for grid, origin and pitch equality. Review verification repeats seed 7 at
both pitches for exact occupancy/origin determinism, and checks a second
seed (19) for structural connectivity. Actual results are in validation.json.

These are technical gates, not a visual verdict. The crown is still dense,
and the lower forks remain deliberately readable. Generalizing the method
to species controls, broader seed variation, seasonal appearance, growth
stages, wind and game performance is outside this one oak pilot.

### Player scale reference added

All comparison, individual, and branch-structure preview tiles now include
the standing game proxy at 1.80 m height. Width is 0.60 m; head, torso, arms
and legs follow `ue-project/Source/VoxelEarth/VoxelProxyBody.cpp`. Standing
height and collision width are defined in `VoxelMovementTuning.h`.
True front elevations use the renderer's voxel-to-pixel ratio to preserve
physical scale, with the player's feet and tree base on one ground line.
The figure is a preview annotation and is not included in exported tree grids.

## Reproduce

From `asset-forge`, with numpy, scipy and Pillow available:

```powershell
python tools/oak_pilot.py --pitch 100 --seed 7 --views
python tools/oak_pilot.py --pitch 50 --seed 7 --views
python tools/oak_pilot_review.py --verify
```

Review creates `out/oak-pilot/baseline/tree.vxa` if missing, using the unchanged
`pipeline.build(spec.load('specs/temperate-oak.json')[0], 7)` and `vxa.write`.
`oak_pilot_review.py --install` installs a fresh draft and refuses to overwrite
an existing model. Dependencies for this session were installed locally under
`.scratch/oak-python`; the bundled Python runtime supplies Pillow.
