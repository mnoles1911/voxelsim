# Red deer stag: static pilot review

Status: ready for user set review. All cubes are 12.5 mm.

Long limbs, short tail, pointed ears and branched antlers; authored brown coat, pale rump, dark muzzle and hooves.

Generic deer sculpt interpreted as a red stag. Antler age and individual measurements are unverified; this is not a mature crown-antler study.

Biological reference: [Red deer stag species account](https://bds.org.uk/information-advice/about-deer/deer-species/red-deer/). This constrains visual plausibility; it is not a measured registration of the source mesh. See attribution.json for the mesh license and modifications.

Orthographic and oblique reviews: `out/creature-reconstruction/red-deer-refined`. Saved model: `red_deer_stag_anatomy_pilot/red_deer_stag_anatomy_pilot-0001`.

Validation: one connected component; exact surface/RGB alignment; 12.5 mm VXA; RGB payload byte equality. Bounds (including pose, fins or antlers): 2.013 × 0.6125 × 2.463 m. Occupied cubes: 205,448.

Static appearance only. Rigging, animation, collisions, LODs and game integration remain separate. Technical checks do not confer visual approval.
