# Rainbow trout: static pilot review

Status: user accepted the static appearance on 2026-09-07. All cubes are 12.5 mm.

University specimen preserves the salmonid silhouette and fin arrangement. Authored olive back, silver belly and pink lateral band.

Scaled uniformly to a large 0.65 m game fish, not the original specimen size. At about 52 voxels long, spots and eye details are deliberately simplified.

Biological reference: [Rainbow trout species account](https://mdc.mo.gov/discover-nature/field-guide/rainbow-trout). This constrains visual plausibility; it is not a measured registration of the source mesh. See attribution.json for the mesh license and modifications.

Orthographic and oblique reviews: `out/creature-reconstruction/rainbow-trout-refined`. Saved model: `rainbow_trout_anatomy_pilot/rainbow_trout_anatomy_pilot-0001`.

Validation: one connected component; exact surface/RGB alignment; 12.5 mm VXA; RGB payload byte equality. Bounds (including pose, fins or antlers): 0.6625 × 0.15 × 0.225 m. Occupied cubes: 2,334.

Static appearance only. Rigging, animation, collisions, LODs and game integration remain separate. Technical checks do not confer visual approval.
