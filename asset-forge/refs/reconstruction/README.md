# Creature reconstruction evidence

Process and lessons: [Astra creature modeling pipeline](../../../docs/astra-creature-modeling-pipeline.md).

The eight static pilot models are user accepted as of 2026-09-07. Species folders retain source attribution, biological references and review evidence. Historical rejected studies are evidence, not the current modeling recipe.

The failed procedural generator and initial raven perch-removal script were retired after the accepted reference-mesh pipeline replaced them. They remain recoverable in Git history before this cleanup. Shared orthographic rendering now lives in `tools/creature_review_views.py`.

Original source GLBs and intermediate renders are cached under ignored `out/creature-reconstruction/`; saved accepted artifacts live in `library/*_anatomy_pilot/`. Their source licenses remain applicable. Static appearance approval does not imply rigging or runtime readiness.
